Regresja

Regresja liniowa prosta

Korelacja mówiła, czy dwie zmienne są powiązane. Regresja idzie dalej: modeluje ten związek i pozwala predykować.

Od korelacji do regresji

Regresja liniowa prosta opisuje związek między jedną zmienną objaśniającą (X) a zmienną zależną (Y) za pomocą linii prostej:

\[Y = \beta_0 + \beta_1 X + \varepsilon\]

\(\beta_0\) — wyraz wolny (intercept): wartość Y gdy X = 0

\(\beta_1\) — nachylenie (slope): o ile zmieni się Y, gdy X wzrośnie o 1

\(\varepsilon\) — błąd losowy (reszty)

Dopasowanie linii regresji

Reszty (residuals)

Reszta to różnica między wartością zaobserwowaną a przewidywaną:

\[e_i = y_i - \hat{y}_i\]

Dobry model ma reszty małe, losowe i bez wzorca.

Używa danych z widgetu powyżej.

\(R^2\) — ile model wyjaśnia?

Współczynnik determinacji \(R^2\) mówi, jaki odsetek zmienności Y jest wyjaśniony przez model.

\[R^2 = 1 - \frac{SS_{res}}{SS_{tot}} = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}\]

Zakres [0, 1]: 0 = model nic nie wyjaśnia, 1 = idealne dopasowanie.

Warning

Uwaga: Wysokie \(R^2\) nie oznacza, że model jest “dobry” — może być przeuczony. Niskie \(R^2\) nie oznacza, że model jest bezwartościowy — w naukach społecznych \(R^2\) = 0.3 jest często bardzo dobre.

Regresja wieloraka

Regresja prosta używała jednego predyktora. W rzeczywistości na Y wpływa wiele czynników jednocześnie.

Wiele predyktorów naraz

Regresja wieloraka rozszerza model o k predyktorów:

\[Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \ldots + \beta_k X_k + \varepsilon\]

Każde \(\beta_j\) mówi: o ile zmieni się Y, gdy \(X_j\) wzrośnie o 1, przy stałych pozostałych zmiennych.

Note

Skorygowane \(R^2\): Zwykłe \(R^2\) zawsze rośnie z każdym dodanym predyktorem (nawet bezużytecznym!). Adjusted \(R^2\) koryguje ten efekt — karze za zbędne zmienne.

Modele z 1, 2, 3 i 4 predyktorami — porównanie metryk.
Warning

Ostrożnie z dodawaniem zmiennych! Więcej zmiennych = większe \(R^2\), ale nie zawsze lepszy model. Przeuczone modele słabo generalizują. Używaj adj. \(R^2\), AIC, BIC.

Regresja logistyczna

Regresja liniowa wymaga ciągłej zmiennej zależnej. A co, gdy Y to 0 lub 1 (sukces/porażka)?

Dlaczego nie regresja liniowa?

Gdy zmienna zależna jest binarna (np. zdany/niezdany egzamin), regresja liniowa daje przewidywania spoza zakresu [0, 1]. Rozwiązanie: regresja logistyczna.

Zamiast modelować Y bezpośrednio, modelujemy prawdopodobieństwo sukcesu:

\[P(Y=1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \ldots + \beta_k X_k)}}\]

Funkcja logistyczna (sigmoida) zamyka wynik w [0, 1].

Interpretacja: iloraz szans

W regresji logistycznej współczynniki interpretujemy przez iloraz szans (odds ratio):

\[OR = e^{\beta_j}\]

OR = 1.5 oznacza: wzrost X o 1 zwiększa szanse sukcesu 1.5-krotnie.

Używa modelu dopasowanego powyżej.

Note

Ocena modelu logistycznego: Nie używamy \(R^2\) w sensie liniowym. Zamiast tego: AIC, BIC, oraz macierz pomyłek (confusion matrix) z dokładnością, czułością i swoistością.

Porównanie modeli

Zbudowaliśmy różne modele. Jak wybrać najlepszy? Poznajmy metryki porównawcze.

Metryki jakości modelu

Nie ma jednej uniwersalnej miary. Każda odpowiada na inne pytanie:

Metryka Co mierzy Lepiej gdy
\(R^2\) Odsetek wyjaśnionej zmienności wyższe
\(R^2_{adj}\) \(R^2\) skorygowane za liczbę predyktorów wyższe
AIC Jakość + złożoność (kara za parametry) niższe
BIC Jak AIC, ale silniejsza kara za parametry niższe
RMSE Średni błąd predykcji (w jednostkach Y) niższe

AIC: \(AIC = -2 \ln(L) + 2k\)

BIC: \(BIC = -2 \ln(L) + k \ln(n)\)

RMSE: \(RMSE = \sqrt{\frac{1}{n}\sum(y_i - \hat{y}_i)^2}\)

gdzie L = wiarygodność, k = liczba parametrów, n = liczba obserwacji

Arena modeli liniowych

Generujemy dane i budujemy 4 modele z różną liczbą predyktorów.
Note

AIC vs BIC: AIC faworyzuje modele z lepszą predykcją (nawet złożone). BIC mocniej karze za złożoność — preferuje prostsze modele. Gdy się nie zgadzają, AIC jest lepszy do predykcji, BIC do wyjaśnienia.

Liniowy vs logistyczny

Co się stanie, jeśli spróbujemy użyć regresji liniowej do predykcji zmiennej binarnej? Porównajmy z logistyczną.

Important

Wniosek: Regresja liniowa na danych binarnych daje predykcje poza [0, 1] i nie jest poprawnym modelem. Zawsze używaj regresji logistycznej dla zmiennej zależnej 0/1.

Przeuczenie (overfitting)

Model z wieloma parametrami może idealnie dopasować się do danych treningowych, ale źle generalizować. Zobaczmy to na wielomianach.

Warning

Złota reguła: Najlepszy model to nie ten z najwyższym \(R^2\), ale ten, który najlepiej generalizuje na nowe dane. Używaj AIC/BIC do wyboru złożoności.

Interpretacja współczynników

Note

Regresja liniowa: \(\beta_1 = 0.5\) oznacza: wzrost X o 1 powoduje wzrost Y o 0.5 (ceteris paribus).

Regresja logistyczna: \(\beta_1 = 0.5 \Rightarrow OR = e^{0.5} = 1.65\) oznacza: wzrost X o 1 zwiększa szanse sukcesu 1.65-krotnie.

Istotność współczynników: p < 0.05 dla \(\beta_j\) oznacza, że predyktor \(X_j\) istotnie wpływa na Y (przy kontroli pozostałych).

Kiedy która regresja?

Tip
  • Y ciągła, 1 predyktor — regresja liniowa prosta
  • Y ciągła, wiele predyktorów — regresja wieloraka
  • Y binarna (0/1) — regresja logistyczna
  • Y porządkowa — regresja porządkowa (ordered logit)
  • Y licznikowa — regresja Poissona

Funkcje R

library(broom)

# === Regresja liniowa ===
model <- lm(y ~ x1 + x2, data = dane)
summary(model)         # pelne podsumowanie
tidy(model)            # wspolczynniki jako tabelka
glance(model)          # metryki (R2, AIC, BIC, ...)

# === Regresja logistyczna ===
model_log <- glm(y ~ x1 + x2, data = dane, family = binomial)
tidy(model_log)
exp(coef(model_log))   # odds ratios
tidy(model_log, conf.int = TRUE, exponentiate = TRUE)  # OR z CI

# === Porownanie modeli ===
AIC(model1, model2, model3)
BIC(model1, model2, model3)

# === Predykcja ===
predict(model, newdata = data.frame(x1 = 5, x2 = 3))
predict(model_log, newdata = ..., type = "response")  # prawdopodobienstwa

Typowe pułapki

Important
  • Extrapolacja: Model działa w zakresie danych treningowych. Predykcja poza tym zakresem jest ryzykowna.
  • Korelacja predyktorów: Silna korelacja między X1 i X2 (współliniowość) zawyża SE i utrudnia interpretację.
  • Overfitting: Więcej zmiennych = wyższe \(R^2\), ale gorsze uogólnianie. Zawsze sprawdzaj adj.\(R^2\) / AIC / BIC.
  • \(R^2\) w logistycznej: Nie używaj \(R^2\) do oceny regresji logistycznej. Użyj AIC, BIC, dokładności, ROC-AUC.
