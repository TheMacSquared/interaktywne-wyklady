Założenia testów

Normalność rozkładu

Wiele testów statystycznych zakłada normalność danych. Jak to sprawdzić i co zrobić, gdy założenie jest naruszone?

Które metody wymagają normalności?

Założenie normalności dotyczy:

  • Test t (jednej próby, niezależny, parowy) — normalność danych (lub reszt)
  • ANOVA — normalność reszt w każdej grupie
  • Korelacja Pearsona — rozkład dwuwymiarowy normalny
  • Regresja liniowa — normalność reszt (nie danych!)

Ważne: Przy dużych próbach (n > 30) testy t i ANOVA są odporne na odchylenia dzięki CTG. Normalność jest kluczowa głównie przy małych próbach.

Wizualne sprawdzanie normalności

Note

Jak czytać Q-Q plot: Jeśli punkty leżą na linii — dane są normalne. Odchylenia na końcach — ciężkie/lekkie ogony. Krzywa — skośność.

Testy formalne

Dwa najczęściej używane testy:

  • Shapiro-Wilk — najlepszy dla n < 50, najczęściej używany
  • Kolmogorov-Smirnov — działa dla dowolnego n, mniej mocny

\(H_0\): dane pochodzą z rozkładu normalnego. p < 0.05 → odrzucamy normalność.

Używa danych z widgetu powyżej.
Warning

Problem z testami formalnymi: Przy dużym n test Shapiro-Wilka odrzuci normalność nawet dla nieistotnych odchyleń. Przy małym n nie ma mocy. Zawsze łącz test z wizualizacją (Q-Q plot)!

Gdy normalność jest naruszona

Opcje:

  1. Zignoruj — przy dużym n (> 30) testy parametryczne są odporne
  2. Użyj alternatywy nieparametrycznej — patrz tabela
  3. Transformuj dane — log, sqrt, Box-Cox

Efekt transformacji logarytmicznej

Generujemy dane prawoskośne i stosujemy log().

Jednorodne wariancje

Normalność to nie jedyne założenie. Wiele testów porównawczych wymaga równych wariancji między grupami.

Homoscedastyczność — równe wariancje

Założenie jednorodnych wariancji (homoscedastyczność) dotyczy:

  • Test t niezależny — wariancje w obu grupach powinny być podobne
  • ANOVA — wariancje we wszystkich grupach porównywalne
  • Regresja liniowa — wariancja reszt stała (homoscedastyczność reszt)

Jak wygląda naruszenie?

Testy jednorodnych wariancji

Dwa popularne testy:

  • Test Levene’a — odporny na naruszenie normalności, zalecany
  • Test Bartletta — mocniejszy, ale wrażliwy na brak normalności

\(H_0\): wariancje są równe we wszystkich grupach.

Używa danych z widgetu powyżej.

Gdy wariancje są nierówne

Opcje:

  1. Test t Welcha — domyślny w R! Nie zakłada równych wariancji. W praktyce zawsze można używać Welcha zamiast klasycznego t.
  2. Mann-Whitney U — nieparametryczny, nie zakłada równych wariancji
  3. ANOVA Welcha — odpowiednik dla 3+ grup (oneway.test())
  4. Regresja: odporne błędy std. — sandwich::vcovHC() + lmtest::coeftest()

Test t klasyczny vs Welcha

Porównanie wyniku: klasyczny test t (zakłada równe wariancje) vs test Welcha (nie zakłada).
Tip

Praktyczna rada: Zawsze używaj testu Welcha (t.test(var.equal = FALSE)) — to domyślne zachowanie w R. Klasyczny test t z równymi wariancjami ma sens tylko gdy masz pewność, że wariancje są równe.

Założenia regresji

Regresja liniowa ma własny zestaw założeń. Naruszenie każdego prowadzi do innego typu problemów.

Pięć założeń regresji liniowej

  1. Liniowość — związek Y~X jest liniowy
  2. Niezależność reszt — reszty nie są skorelowane
  3. Homoscedastyczność — wariancja reszt stała
  4. Normalność reszt — reszty ~N(0, σ)
  5. Brak współliniowości — predyktory nie są silnie skorelowane

Kluczowe: założenia dotyczą reszt, nie surowych danych!

Diagnostyka wizualna

Note

Jak czytać wykresy diagnostyczne:

  • Reszty vs dopasowane: losowy rozrzut = OK, wzór = problem
  • Q-Q reszt: punkty na linii = normalność OK
  • Scale-Location: płaska linia = homoscedastyczność OK

Założenia χ² i Fishera

Testy dla zmiennych jakościowych mają prostsze, ale ważne założenia dotyczące minimalnych liczności.

Założenia testu χ²

Test chi-kwadrat (zgodności i niezależności) wymaga:

  1. Niezależność obserwacji — każda obserwacja należy do jednej kategorii
  2. Oczekiwane liczności ≥ 5 — w każdej komórce tabeli
  3. Próba losowa z populacji

Gdy oczekiwane liczności < 5, test χ² jest niedokładny.

Efekt małych liczności

Generujemy 500 prób z H₀ prawdziwą (brak związku). Sprawdzamy, jak często każdy test fałszywie odrzuci H₀.
Important

Problem: Przy małych n, test χ² może dawać za dużo lub za mało fałszywych alarmów (niekontrolowany błąd I rodzaju). Test Fishera zachowuje się poprawnie.

Kiedy χ², kiedy Fisher?

Tip

Zasady:

  • Wszystkie oczekiwane ≥ 5 → test χ²
  • Którakolwiek oczekiwana < 5 → test Fishera
  • Tabela 2×2 z małym n → zawsze Fisher
  • Duża tabela + małe oczekiwane → χ² z symulacją Monte Carlo (chisq.test(simulate.p.value = TRUE))
Note

Założenia testu Fishera: Test Fishera nie ma założeń dotyczących minimalnych liczności — jest testem dokładnym. Wymaga jedynie niezależności obserwacji i stałych sum brzegowych.

Praktyczne rady

Tip
  • Wizualizacja > testy formalne. Wykresy dają intuicję, testy dają liczbę. Używaj obu.
  • Testy Welcha są domyślne w R. Nie musisz sprawdzać równości wariancji przed testem t.
  • Duże n łagodzi naruszenia. Przy n > 30 testy parametryczne są odporne na brak normalności (CTG).
  • Testy nieparametryczne nie są “gorsze”. Mają mniejszą moc przy spełnionych założeniach, ale są bezpieczniejsze ogólnie.
  • Raportuj zawsze wielkość efektu — p-wartość nie mówi, jak duży jest efekt.

Kod R — diagnostyka

library(rstatix)
library(lmtest)

# === Normalność ===
data %>% shapiro_test(variable)               # per zmienna
data %>% group_by(group) %>% shapiro_test(var) # per grupa

# === Równe wariancje ===
data %>% levene_test(var ~ group)
bartlett.test(var ~ group, data = data)

# === Diagnostyka regresji ===
model <- lm(y ~ x1 + x2, data = dane)
plot(model)                    # 4 wykresy diagnostyczne
lmtest::bptest(model)          # Breusch-Pagan
lmtest::dwtest(model)          # Durbin-Watson
car::vif(model)                # VIF (współliniowość)

# === Odporne błędy standardowe ===
library(sandwich)
lmtest::coeftest(model, vcov = sandwich::vcovHC(model, type = 'HC3'))

# === Welch ANOVA (nierówne wariancje) ===
oneway.test(var ~ group, data = data)
