Wnioskowanie statystyczne

Logika testowania hipotez

Przedziały ufności mierzą niepewność estymacji. Teraz przejdziemy do pytania: czy zaobserwowany efekt jest rzeczywisty?

Testowanie hipotez — logika rozumowania

Testowanie hipotez statystycznych przypomina proces sądowy:

  • \(H_0\) (hipoteza zerowa) = “oskarżony jest niewinny” — brak efektu, brak różnicy
  • \(H_1\) (hipoteza alternatywna) = “oskarżony jest winny” — efekt istnieje
  • Dane = dowody przedstawione w sądzie
  • p-wartość = jak bardzo dane są zaskakujące, jeśli \(H_0\) jest prawdziwa

Jeśli p-wartość jest mniejsza niż przyjęty poziom istotności \(\alpha\) (zwykle 0.05), odrzucamy \(H_0\) na korzyść \(H_1\).

Co to jest p-wartość?

P-wartość to prawdopodobieństwo uzyskania wyniku co najmniej tak skrajnego jak zaobserwowany, zakładając, że \(H_0\) jest prawdziwa.

Zobaczmy to na symulacji: losujemy próby z populacji, w której \(H_0\) jest prawdziwa, i obserwujemy rozkład statystyki testowej.

Populacja: N(μ=170, σ=10). Testujemy H₀: μ = 170.
Note

Obserwacja: Gdy \(H_0\) jest prawdziwa, p-wartości mają rozkład jednostajny [0, 1]. Około 5% prób da p < 0.05 — to są fałszywe alarmy (błąd I rodzaju)!

Błędy I i II rodzaju

Każda decyzja może być błędna:

\(H_0\) prawdziwa \(H_0\) fałszywa
Nie odrzucamy \(H_0\) OK Błąd II rodzaju (\(\beta\))
Odrzucamy \(H_0\) Błąd I rodzaju (\(\alpha\)) OK (moc = \(1-\beta\))
Warning

Kompromis: Zmniejszenie \(\alpha\) redukuje błąd I rodzaju, ale zwiększa błąd II rodzaju. Jedyny sposób na zmniejszenie obu: zwiększenie n!

Formułowanie hipotez

Znamy logikę testowania: \(H_0\), \(H_1\), p-wartość, decyzja. Ale jak przejść od pytania badawczego do formalnej hipotezy?

Od pytania do hipotezy

W badaniach pytania są formułowane swobodnym językiem:

  • “Czy mężczyźni są wyżsi od kobiet?”
  • “Czy korepetycje pomagają?”
  • “Czy lodów sprzedaje się więcej w ciepłe dni?”

Ale test statystyczny wymaga formalnych hipotez: precyzyjnych stwierdzeń o parametrach populacji, które można zweryfikować danymi.

Najważniejsza zasada: \(H_0\) zawsze zawiera znak równości (=, \(\leq\), \(\geq\)). \(H_1\) zawiera to, co chcemy wykazać (\(\neq\), >, <).

Note

Szablon:

\(H_0\): brak efektu / brak różnicy / brak związku

\(H_1\): jest efekt / jest różnica / jest związek

Galeria przykładów: pytanie → hipoteza

Przeglądaj przykłady — każdy pokazuje, jak przejść od potocznego pytania do formalnych hipotez.

Ćwiczenie: sformułuj hipotezę

Dostajesz pytanie badawcze w języku potocznym. Twój cel: wybrać poprawną parę \(H_0\)/\(H_1\).

Odwrotnie: hipoteza → co badamy?

Jednostronny vs dwustronny test

Sformułowanie \(H_1\) decyduje, czy test jest jedno- czy dwustronny:

Typ \(H_1\) Przykład Kiedy?
Dwustronny \(\mu_1 \neq \mu_2\) “Czy grupy się różnią?” Gdy nie wiesz, w którą stronę — domyślny wybór
Prawostronny \(\mu_1 > \mu_2\) “Czy lek jest lepszy od placebo?” Gdy masz silne podstawy teoretyczne dla kierunku
Lewostronny \(\mu_1 < \mu_2\) “Czy nowa metoda jest szybsza?” Gdy oczekujesz niższej wartości
Warning

W wątpliwości: Używaj testu dwustronnego. Test jednostronny jest mocniejszy (większa moc), ale ryzykowny: jeśli efekt jest w przeciwnym kierunku, nie możesz go wykryć. Test jednostronny powinien być zaplanowany przed zbieraniem danych.

Typowe błędy przy formułowaniu hipotez

Important
  1. \(H_0\) z nierównością: Źle: \(H_0: \mu_1 \neq \mu_2\). \(H_0\) zawsze zawiera = (ewentualnie \(\leq\) lub \(\geq\)).
  2. Hipoteza o próbie zamiast populacji: Źle: “H0: średnia w próbie = 170”. Hipotezy dotyczą parametrów populacji, nie statystyk z próby.
  3. Brak precyzji: Źle: “H0: dane są dobre”. Hipoteza musi precyzyjnie określać parametr i wartość.
  4. Zmiana hipotezy po zobaczeniu danych (HARKing): Hipotezy formułujemy PRZED analizą, nie po!
  5. Mylące \(H_0\) i \(H_1\): \(H_1\) to to, co chcesz wykazać. \(H_0\) to “stan domyślny” (brak efektu). Nie odwracaj ich.

Jedna zmienna ilościowa

Znamy logikę testowania i formułowanie hipotez. Czas na pierwszy konkretny test: czy średnia/mediana różni się od zakładanej wartości?

Test t jednej próby

Pytanie: Czy średnia w populacji różni się od wartości \(\mu_0\)?

\(H_0: \mu = \mu_0 \quad\text{vs}\quad H_1: \mu \neq \mu_0\)

\(t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}, \quad df = n - 1\)

Wymaga: dane ilościowe, w przybliżeniu normalne (lub duże n dzięki CTG).

Interaktywny test t

Test Wilcoxona jednej próby

Alternatywa nieparametryczna dla testu t. Testuje, czy mediana różni się od wartości \(\mu_0\).

Nie wymaga normalności — działa na rankingach. Mniej moc gdy dane są normalne, ale odporny na outliery i skośność.

Używa tych samych danych co test t powyżej.

Porównanie: t vs Wilcoxon

Który test daje lepsze wyniki? To zależy od rozkładu danych. Porównajmy oba na danych z różnych rozkładów.

Generujemy 200 prób z H₁ prawdziwą (mały efekt). Porównujemy moc obu testów.
Note

Kiedy który?

  • Test t — dane w przybliżeniu normalne, brak ekstremalnych outlierów
  • Wilcoxon — wyraźna skośność, outliery, mała próba + wątpliwa normalność

Jedna zmienna jakościowa

Testowaliśmy średnią jednej zmiennej ilościowej. A co, gdy zmienna jest jakościowa (kategorialna)?

Test chi-kwadrat zgodności

Pytanie: Czy rozkład obserwowany różni się od oczekiwanego?

Przykłady: czy kostka jest uczciwa? Czy studenci wybierają kierunki równomiernie?

\(H_0\): rozkład zgodny z oczekiwanym

\(\chi^2 = \sum \frac{(O_i - E_i)^2}{E_i}\)

gdzie \(O_i\) = liczności obserwowane, \(E_i\) = liczności oczekiwane

Czy kostka jest uczciwa?

Note

Interpretacja: Duża wartość \(\chi^2\) oznacza dużą rozbieżność między tym, co zaobserwowaliśmy, a tym, czego oczekiwaliśmy. Jeśli p < 0.05, rozbieżność jest zbyt duża, by być przypadkiem.

Test dwumianowy

Gdy zmienna ma dokładnie dwie kategorie (sukces/porażka), możemy użyć testu dwumianowego.

Pytanie: Czy proporcja sukcesów różni się od \(p_0\)?

Przykład: rzucamy monetą — czy jest uczciwa (p = 0.5)?

Warning

Uwaga: Test dwumianowy jest dokładny (nie opiera się na przybliżeniu) — działa nawet przy bardzo małych próbach. Test \(\chi^2\) zgodności wymaga, żeby każda oczekiwana liczność \(\geq\) 5.

Dwie zmienne ilościowe (korelacja)

Dotychczas badaliśmy jedną zmienną. Teraz pytamy: czy dwie zmienne ilościowe są ze sobą powiązane?

Korelacja Pearsona

Współczynnik korelacji Pearsona \(r\) mierzy liniowy związek między dwiema zmiennymi.

\(H_0: \rho = 0\) (brak korelacji liniowej)

\(r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum(x_i-\bar{x})^2 \cdot \sum(y_i-\bar{y})^2}}\)

Interaktywna korelacja

Korelacja Spearmana

Korelacja Spearmana mierzy monotoniczność związku (niekoniecznie liniowy). Działa na rangach — jest odporna na outliery.

Zobaczmy dane, gdzie związek jest monotoniczny, ale nie liniowy:

Note

Kiedy który?

  • Pearson — związek liniowy, dane ~normalne, brak ekstremalnych outlierów
  • Spearman — związek monotoniczny (niekoniecznie liniowy), dane porządkowe, outliery

Korelacja ≠ przyczynowość

Wysoka korelacja nie oznacza, że jedna zmienna powoduje zmianę drugiej. Zobaczmy, jak jeden outlier może sztucznie wytworzyć korelację.

Dane: 50 punktów bez korelacji. Kliknij, aby dodać outliera.
Important

Pamiętaj: Przed interpretacją korelacji zawsze obejrzyj wykres! Pojedynczy punkt może drastycznie zmienić wartość r.

Dwie zmienne jakościowe

Badaliśmy korelację między zmiennymi ilościowymi. A co, gdy obie zmienne są jakościowe (kategorialne)?

Test \(\chi^2\) niezależności

Pytanie: Czy dwie zmienne jakościowe są ze sobą powiązane?

Przykłady: czy płeć wpływa na wybór kierunku? Czy grupa krwi zależy od regionu?

\(H_0\): zmienne są niezależne

\(E_{ij} = \frac{n_{i \cdot} \cdot n_{\cdot j}}{n}\)

\(\chi^2 = \sum \frac{(O_{ij} - E_{ij})^2}{E_{ij}}\)

Test niezależności w akcji

Note

Cramer’s V: Wielkość efektu dla \(\chi^2\). Zakres [0, 1]: < 0.1 pomijalny, 0.1-0.3 mały, 0.3-0.5 średni, > 0.5 duży.

Test dokładny Fishera

Gdy oczekiwane liczności są małe (< 5), test \(\chi^2\) jest niedokładny. Wtedy używamy testu dokładnego Fishera.

Przykład: tabela 2x2 z niewielką próbą.

Warning

Reguła: Gdy którakolwiek oczekiwana liczność < 5, użyj testu Fishera. W R: fisher.test(). Dla tabel większych niż 2x2 można też użyć symulacji Monte Carlo: chisq.test(simulate.p.value = TRUE).

Ilościowa vs jakościowa (dwie grupy)

Badaliśmy związki dwóch zmiennych tego samego typu. Teraz klasyczne pytanie: czy dwie grupy różnią się?

Test t dla dwóch prób niezależnych

Pytanie: Czy średnie w dwóch grupach różnią się istotnie?

Przykład: czy mężczyźni i kobiety różnią się wzrostem?

\(H_0: \mu_1 = \mu_2 \quad\text{vs}\quad H_1: \mu_1 \neq \mu_2\)

\(t = \frac{\bar{x}_1 - \bar{x}_2}{SE}\)

Test t niezależny

Test t dla prób zależnych (parowy)

Gdy mierzymy tych samych osobników dwa razy (przed i po interwencji), używamy testu parowego.

Przykład: wyniki studentów przed i po korepetycjach.

Testujemy różnice: \(d_i = x_{\text{po},i} - x_{\text{przed},i}\). Pytamy, czy średnia różnic \(\neq\) 0.

Mann-Whitney U (nieparametryczny)

Odpowiednik nieparametryczny testu t niezależnego. Testuje, czy rozkłady w dwóch grupach się różnią (ranga).

Używaj, gdy dane nie są normalne lub są porządkowe.

Używa tych samych danych co test t niezależny powyżej.

Wilcoxon par znakowych (nieparametryczny parowy)

Nieparametryczny odpowiednik testu t parowego. Działa na rangach różnic.

Używa tych samych danych parowych co test t parowy powyżej.
Note

Podsumowanie:

Typ Parametryczny Nieparametryczny
Niezależne Test t Mann-Whitney U
Parowe Test t parowy Wilcoxon par znakowych

ANOVA

Porównywaliśmy dwie grupy. A co, gdy grup jest trzy lub więcej?

ANOVA jednoczynnikowa

ANOVA (Analysis of Variance) to uogólnienie testu t na 3 lub więcej grup.

Pytanie: Czy średnie w k grupach różnią się istotnie?

Przykład: czy średnie oceny różnią się między 4 kierunkami studiów?

\(H_0: \mu_1 = \mu_2 = \ldots = \mu_k\)

\(F = \frac{MS_{\text{między}}}{MS_{\text{wewnątrz}}} = \frac{\text{zmienność między grupami}}{\text{zmienność wewnątrz grup}}\)

Duże F oznacza: grupy różnią się bardziej niż moglibyśmy oczekiwać przypadkiem.

ANOVA w akcji

Note

Dekompozycja wariancji: Całkowita zmienność = zmienność między grupami + zmienność wewnątrz grup. ANOVA testuje, czy ta “między” część jest istotnie duża.

Testy post-hoc (Tukey HSD)

ANOVA mówi “grupy różnią się”, ale nie mówi “które”.

Do tego służą testy post-hoc. Tukey HSD porównuje każdą parę grup z korektą na wielokrotne porównania.

Używa danych z ANOVA powyżej. Najpierw uruchom ANOVA!
Warning

Ważne: Testy post-hoc wykonujemy tylko gdy ANOVA jest istotna. Bez tego korekcja na wielokrotne porównania jest niepotrzebna.

Kruskal-Wallis (nieparametryczny)

Odpowiednik nieparametryczny ANOVA — test Kruskala-Wallisa.

Działa na rangach, nie wymaga normalności. Post-hoc: test Dunna z korektą.

Używa tych samych danych.
Note

Podsumowanie:

Parametryczny Nieparametryczny
Główny test ANOVA Kruskal-Wallis
Post-hoc Tukey HSD Test Dunna

Ściąga

Kompaktowe podsumowanie wszystkich testów z tego wykładu.

Drzewo decyzyjne: jaki test?

Note

Krok 1: Ile zmiennych?

  • Jedna zmienna → Krok 2a
  • Dwie zmienne → Krok 2b

Krok 2a: Jedna zmienna — jaki typ?

  • Ilościowa → test t jednej próby / Wilcoxon
  • Jakościowa (2 kat.) → test dwumianowy
  • Jakościowa (3+ kat.) → \(\chi^2\) zgodności

Krok 2b: Dwie zmienne — jakie typy?

  • Ilościowa + ilościowa → Pearson / Spearman
  • Jakościowa + jakościowa → \(\chi^2\) niezależności / Fisher
  • Ilościowa + jakościowa (2 grupy) → Krok 3
  • Ilościowa + jakościowa (3+ grup) → ANOVA / Kruskal-Wallis

Krok 3: Próby niezależne czy parowe?

  • Niezależne → test t / Mann-Whitney
  • Parowe → test t parowy / Wilcoxon par znakowych

P-wartość — przypomnienie

Tip

P-wartość to: Prawdopodobieństwo uzyskania wyniku co najmniej tak skrajnego, zakładając że \(H_0\) jest prawdziwa.

Important

P-wartość NIE jest:

  • Prawdopodobieństwem, że \(H_0\) jest prawdziwa
  • Prawdopodobieństwem, że wynik jest przypadkowy
  • Miarą wielkości efektu (p = 0.001 \(\neq\) duży efekt!)

Typowe pułapki

Important
  • P-hacking: testowanie wielu porównań i raportowanie tylko istotnych — zwiększa błąd I rodzaju
  • Wielokrotne porównania: przy k grupach jest k(k-1)/2 par. Bez korekcji (Bonferroni, Tukey) ryzyko fałszywych alarmów rośnie
  • Brak istotności \(\neq\) brak efektu: może brakować mocy (za małe n)
  • Istotność statystyczna \(\neq\) istotność praktyczna: przy n = 10 000 nawet trywialna różnica może być istotna. Zawsze podawaj wielkość efektu!

Kod R — rstatix

library(rstatix)
library(broom)

# === Jedna zmienna ===
# Test t jednej próby
data %>% t_test(oceny ~ 1, mu = 3.5)

# Wilcoxon jednej próby
data %>% wilcox_test(oceny ~ 1, mu = 3.5)

# === Korelacja ===
data %>% cor_test(wzrost, waga, method = "pearson")
data %>% cor_test(wzrost, waga, method = "spearman")

# === Dwie grupy ===
# Niezależne
data %>% t_test(wzrost ~ plec)
data %>% wilcox_test(wzrost ~ plec)
data %>% cohens_d(wzrost ~ plec)

# Parowe
data %>% t_test(wynik ~ moment, paired = TRUE)
data %>% wilcox_test(wynik ~ moment, paired = TRUE)

# === Chi-kwadrat ===
tab <- table(data$plec, data$kierunek)
chisq.test(tab)
fisher.test(tab)

# === ANOVA ===
data %>% anova_test(oceny ~ kierunek)
data %>% tukey_hsd(oceny ~ kierunek)

# Kruskal-Wallis
data %>% kruskal_test(oceny ~ kierunek)
data %>% dunn_test(oceny ~ kierunek, p.adjust.method = "holm")
