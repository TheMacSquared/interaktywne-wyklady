# Interaktywne Wykłady z Ekonometrii

Ten katalog jest miejscem na nowy, równoległy zestaw aplikacji R Shiny do nauczania ekonometrii.

## Planowana struktura

```text
ekonometria/
├── README.md
├── R/                  # wspólne komponenty i style dla ekonometrii
└── nazwa-wykladu/
    ├── app.R
    └── modules/
```

Na starcie katalog nie zawiera jeszcze aplikacji. Przy dodawaniu pierwszego wykładu warto zdecydować, czy ekonometria ma skopiować system layoutu ze `statystyka/R/`, czy rozwijać własny wariant współdzielonych komponentów.
