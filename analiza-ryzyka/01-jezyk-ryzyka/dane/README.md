# Dane wykładu 01

Wersja MVP nie wymaga zewnętrznego zbioru danych. Parametry symulacji oraz
metadane zdarzeń są zdefiniowane w `analiza-ryzyka/R/bananpol.R` i oznaczone jako
fikcyjne.

W przyszłej wersji ćwiczeniowej ten katalog może zawierać rejestr incydentów w
CSV wraz ze słownikiem zmiennych i skryptem generującym dane.
