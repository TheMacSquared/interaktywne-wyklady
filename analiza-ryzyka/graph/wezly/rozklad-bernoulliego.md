# Rozkład Bernoulliego

**Definicja.** Pojedyncza próba 0/1 z prawdopodobieństwem sukcesu p.

**Intuicja.** Atom wszystkich modeli zliczających: jedna inspekcja, jeden cykl, jedno żądanie.
