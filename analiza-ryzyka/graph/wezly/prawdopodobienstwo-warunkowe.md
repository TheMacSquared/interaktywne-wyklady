# Prawdopodobieństwo warunkowe

**Definicja.** P(A|B) = P(A∩B)/P(B) — prawdopodobieństwo A po zawężeniu przestrzeni do B.

**Intuicja.** Warunek nie „zmienia świata", tylko zmienia mianownik: liczymy w mniejszym uniwersum.
