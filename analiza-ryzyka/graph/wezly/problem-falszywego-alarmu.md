# Problem fałszywego alarmu

**Pytanie.** Sygnał diagnostyczny (alarm, test, inspekcja) jest pozytywny — jakie jest prawdopodobieństwo, że stan faktycznie jest awaryjny?

**Intuicja.** Klasa pytań, w których intuicja systematycznie ignoruje częstość bazową.
