# Rozkład wykładniczy

**Definicja.** R(t) = exp(−λt); jedyny rozkład ciągły bez pamięci, stały hazard λ.

**Intuicja.** Awarie czysto losowe: element „nie wie", ile już przepracował. Ciągły odpowiednik geometrycznego.
