# Pojedynczy Weibull nie tworzy całej krzywej wannowej

Przy stałym parametrze kształtu hazard Weibulla jest malejący, stały albo
rosnący. Pełna krzywa wannowa wymaga modelu złożonego lub zmiennego mechanizmu.
